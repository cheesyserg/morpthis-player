Fonts in this folder, and the licences they are used under
============================================================

The firmware's own faces -- default.otf, bold.otf, korean.otf, thai.otf,
arabic.otf, japanese.otf and Neon.ttf -- are the ones Sonix Player and the
stock firmware have always shipped. This file covers the four families added
for Settings -> Appearance -> UI font, each with the licence it is published
under and the file it was taken from. Every one of them is used unmodified.

Source: https://github.com/google/fonts/tree/bd8f81ddb5c74d5c8897b36ad88b440266245103/ofl/roboto/Roboto[wdth,wght].ttf
